INGEPRO - CALCULADORA DE PILOTES

ARCHIVOS
- index.html: calculadora
- manifest.json: permite instalar como acceso directo/PWA
- sw.js: permite funcionamiento offline despues de la primera carga
- icon.svg: icono

PUBLICACION RAPIDA EN GITHUB PAGES
1. Crear un repositorio nuevo en GitHub.
2. Subir los cuatro archivos manteniendolos en la raiz.
3. Ir a Settings > Pages.
4. En Build and deployment seleccionar Deploy from a branch.
5. Seleccionar la rama main y carpeta /(root), y guardar.
6. GitHub mostrara la direccion publica de la calculadora.

EN EL CELULAR
Android/Chrome: abrir el enlace > menu > Agregar a pantalla principal / Instalar app.
iPhone/Safari: abrir el enlace > Compartir > Agregar a inicio.

Uso: ingresar cantidad, diametro en cm y profundidad en m. El calculo es automatico.
